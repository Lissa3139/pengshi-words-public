FSRS algorithm notice
=====================

The local scheduling engine in this module is an app-owned, dependency-free
implementation of the FSRS-6 formulas and is designed to be replaceable behind
the FsrsEngine interface.

Algorithm and Kotlin implementation references:
- FSRS algorithm documentation by the Open Spaced Repetition project:
  https://github.com/open-spaced-repetition/fsrs4anki/wiki/The-Algorithm
- FSRS-Kotlin v6 reference implementation, main commit
  670f2f895f316a9f78dfd19b991d9bc523c9b037:
  https://github.com/open-spaced-repetition/FSRS-Kotlin
