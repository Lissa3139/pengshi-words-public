# 参考与致谢

感谢**墨墨背单词**公开分享间隔复习研究和产品经验。它对如何安排复习、如何向学习者呈现记忆变化的思考，为彭式背单词的设计提供了参考。我们的部分学习流程与统计展示也受到这类产品实践的启发。

墨墨公开的论文是 *A Stochastic Shortest Path Algorithm for Optimizing Spaced Repetition Scheduling*（ACM SIGKDD 2022）。可阅读[墨墨官方论文介绍](https://www.maimemo.com/paper/)、[论文 DOI 页面](https://doi.org/10.1145/3534678.3539081)和[其公开实现仓库](https://github.com/maimemo/SSP-MMC)。这些链接指向原作者内容，建议对算法细节直接阅读原文。

彭式背单词的长期复习调度使用项目中的 FSRS 实现；同日再现由当天队列处理。我们没有把墨墨论文中的 SSP-MMC 算法、代码或模型文件作为本项目实现。相关来源及许可证另见[第三方资源与版权说明](../THIRD_PARTY_NOTICES.md)。

此处致谢旨在明确参考来源，不表示墨墨背单词对本项目的授权、参与或认可。彭式背单词是独立的开源项目。
