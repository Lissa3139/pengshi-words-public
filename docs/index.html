把注意力留给单词。

简单清楚的学习流程，搭配可调整的词库与计划。

复习优先

先处理到期复习，再进入新词。每日计划与额度清楚显示，可按自己的安排调整。

词库由你选择

使用内置词库，导入自己的词表，或在多个词库之间调整参与选词的范围。

断网也能学习

内置词库与语音可离线使用。Android 和 Windows 都能朗读单词与例句。

数据由你掌握

学习记录保存在本地；需要跨设备时，可自行配置 GitHub 私有仓库加密同步。
