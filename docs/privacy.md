# 隐私与数据

## 数据存在哪里

词条、学习计划、反馈、统计和设置保存在手机的应用私有存储中。内置词库与语音模型属于公共资源；仓库不包含维护者或其他用户的学习记录、数据库、同步快照、令牌和设备备份。

Windows 版默认将数据库保存在 `%LOCALAPPDATA%\PengshiWordsOpenSource\pengshi-words.db`，也可在设置中选择其他文件夹。外部语音模型默认保存在安装目录旁；若那里不能写入，则保存在当前用户目录，也可自行更换。配置 GitHub 私有仓库后，两端都可同步加密学习数据；语音模型文件不会同步。卸载应用前请备份需要保留的数据。

应用没有要求先注册账号才能使用本地学习。当前源码没有接入广告或第三方统计 SDK。

## 哪些功能联网

| 功能 | 数据与用途 |
| --- | --- |
| 内置词库、复习、内置英语朗读 | 在本地处理，无需联网合成 |
| 缺失例句补充 | 向 Tatoeba 发送查询单词，请求双语例句；网络失败时保留本地内容 |
| 安卓可选模型下载 | 用户点击下载后，应用从 Sherpa-ONNX 官方发布页取得模型压缩包，校验后解压到本应用私有目录；不安装其他 App；可在语音管理页删除 |
| 外部语音引擎朗读 | 将待朗读文字交给用户安装的对应 Android TTS 服务；只提供标记为离线的英语音色，但引擎自身的数据行为仍由其实现决定 |
| Windows 外部模型朗读 | 在本机读取用户放入模型目录的 Piper 文件并离线合成语音 |
| GitHub 同步 | 配置并启用后，把加密学习快照和增量写入用户指定的私有仓库，网络请求也包含访问该仓库所需的凭据 |

“未配置同步不联网”仅适用于 GitHub 同步，不代表缺失例句查询也不会联网。

## 凭据和备份

GitHub Token 与同步密码在 Android 上使用 Android Keystore 支持的本地加密存储，在 Windows 上使用当前账户的 DPAPI 加密保存。不要把它们写入源码、截图、日志或 Issue。同步使用的密码与 GitHub 登录密码用途不同；备份导出文件不包含这些同步凭据。

导出的学习备份仍含有个人词条和学习记录，应按私密文件保存。应用私有存储中的自动备份会滚动保留；卸载和清除应用数据可能将其删除。

Android 清单允许系统备份；是否执行、备份位置和恢复方式由设备及系统备份设置决定。需要只在本机保留数据时，同时检查手机系统的应用备份设置。

## 删除数据

删除或清除手机应用数据会移除本机记录。手动导出的文件、GitHub 私有仓库以及 Android 系统备份是独立副本，需要用户在相应位置另行删除。清除数据前先确认是否需要保留学习进度。
