# 使用指南

## 安装应用

Android 版支持 Android 8.0 及以上 ARM64 设备；Windows 桌面版支持 Windows 10/11 x64。正式发行包从本仓库 Releases 页面下载，无需下载源码。

Android 用户打开 APK 并按系统提示安装。Windows 用户打开 MSI 并按安装向导操作。两端都自带 LJSpeech 英语音色；额外音色的安装方法因平台而异，见[语音模型指南](voice-models.md)。

如果已有同名 Android 应用，先导出学习备份。只有应用标识、签名和版本兼容时才能直接覆盖安装；公开首发版本重新从 1.0.0 / versionCode 1 开始，旧开发版可能无法直接升级。不要为了安装新版本直接清除已有学习数据。Windows 本地数据库默认保存在 `%LOCALAPPDATA%\PengshiWordsOpenSource\pengshi-words.db`，卸载或重装前请自行备份实际选用的目录。

## 开始学习

1. 在「词库」选择四级、六级或只读的「考研英语(2024大纲)」等内置词库，或导入自己的词库。考研词库中的小学常见词保留供搜索和手动添加，不占自动安排的每日新词名额。
2. 在选词界面选择要学习的范围，返回首页开始当天任务。
3. 按当前模式查看单词或中文释义，提交记忆反馈；应用按学习情况安排后续复习。
4. 通过朗读按钮听发音；可在「设置」调整自动朗读、语速和默认音色。
5. 在统计页面查看学习记录和复习情况。统计曲线是根据已有学习数据计算的参考信息。

## 导入自己的词库

进入「设置 → 导入本地词库」，选择 CSV、TXT 或 XLSX。文本文件使用 UTF-8 编码；TXT 可以用制表符或逗号分隔，XLSX 读取第一张工作表。

建议使用表头 `spelling,definitionCn,phonetic,partOfSpeech,exampleEn,exampleCn,tags,frequencyRank`。其中单词与中文释义是最常用字段，其余可留空。中文表头「单词」「中文释义」也能识别。

最简单的 CSV：

```csv
spelling,definitionCn
apple,苹果
learn,学习
```

包含逗号的字段要用双引号包围。导入用于新增或补充词条，不会主动清空已有学习进度。导入前建议导出一次备份。

## 使用更多语音

两端都自带 LJSpeech 美式女声。Android 在「设置 → 接入 / 管理语音模型」中下载预设模型，或导入其他英语 Piper 模型文件夹，均可在应用内删除；Windows 在「设置 → 本地语音模型」中打开或更换模型文件夹，放入 Piper 模型后刷新。安装步骤见[语音模型指南](voice-models.md)。两端最多同时启用三个音色，模型文件不随 GitHub 同步。

## 保护学习进度

在「设置 → 导出学习备份」选择保存位置。备份含有自己的学习内容，按个人文件妥善保存。通过「恢复学习备份」选择备份文件恢复数据；恢复前先导出当前数据。

应用还在私有存储中保留滚动备份，但卸载或清除应用数据可能一并删除这些文件。换机前请主动导出文件。

## 可选的 GitHub 同步

不配置同步也可以正常学习。需要多设备同步时：

1. 在自己的 GitHub 账号下创建专用于学习数据的**私有仓库**，初始化 `main` 分支。
2. 为该仓库创建 Fine-grained Token，只给该仓库 `Contents` 读写权限。GitHub 还会默认提供对公开仓库的只读访问。不要分享这个令牌。
3. 在「设置 → GitHub 同步」填入仓库所有者、仓库名、分支、同步密码和 Token，保存连接后同步。
4. 其他设备使用相同仓库与同步密码，并配置自己的访问令牌。同步密码用于加密，丢失后不能指望从服务端恢复明文数据。

从建立私有数据仓库、创建最小权限 Token 到首次多设备同步的完整步骤，见[GitHub 私有同步教程](github-sync.md)。

Android 与 Windows 都有「设置 → GitHub 同步」入口。Windows 的 Token 和同步密码保存在当前 Windows 账户的本地加密设置中；更换数据库文件夹不会自动移动这些凭据。

换机时，先在保存完整学习历史的设备上完成一次同步，再到新设备使用同一仓库和同步密码同步。新设备即使预装了不同数量的词条，也会恢复学习历史和选词设置；本机新增词条会保留。若界面显示“等待依赖”或“冲突”，同步尚未完成，请勿清除原设备数据。

公开项目源码仓库与自己的私有学习数据仓库用途不同，个人数据应保留在私有仓库。请勿把学习备份作为公开 Issue 附件。网络行为和凭据存储见[隐私说明](privacy.md)。
